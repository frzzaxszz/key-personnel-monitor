## ⚠️ 数据声明（务必阅读）

本仓库及运行后自动生成的**所有人员、走访、预警等数据均为 AI 生成的虚拟演示数据**，仅用于可视化展示与功能演示，**不含任何真实公民信息**。

- 后端启动时会自动生成 5000 条虚拟重点人员数据（覆盖全国 31 省）用于演示。
- 你通过 Excel 导入 / 页面新增的数据会叠加进**本地数据库**（不上传至本仓库）。
- 严禁在本项目存放或导入真实公民个人信息。

## 技术栈

- 后端：Python 3.7+ / FastAPI / SQLAlchemy / openpyxl / PyMySQL
- 数据库：MySQL（默认本地） / SQLite（兜底），配置可持久化
- 前端：Vue3 + Vite + ECharts

## 快速开始

### 一键启动
双击根目录 `启动系统.bat`，自动拉起后端(8000)与前端(5173)并打开大屏。

### 手动启动
```bash
# 后端
cd backend
.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000

# 前端
cd frontend
npm run dev
```

## 核心功能

- 中央中国地图（单 geo 图层热力着色 + 风险点打点，钻取省市聚焦）
- 指标栏：重点人员总数 / 高风险 / 今日新增环比 / 在控率 / 待处置预警
- 多图表联动钻取：省份、人员类别、风险等级、管控状态、预警类型、时间趋势
- 人员管理：列表 / 搜索 / 增删改 / 照片上传 / 走访记录
- 数据导入：Excel 按表头映射，必填校验 + 缺失字段默认值兜底
- 系统设置：MySQL 连接配置、模拟数据重建/清空
